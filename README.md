# Меню задач.


Данный проект поможет составить план на день.

Возможности данной программы:
- Показывать задачи
- Добавлять задачи
- Удалять задачи
- Выходить из программы

## Как запустить

Нужен установленный Python 3. Открой терминал в папке программы и выполни:

```powershell
python d8_menu.py
```

Задачи хранятся только во время работы программы. После выхода изменения не сохраняются.
