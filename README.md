# Меню задач.


Данный проект поможет составить список задач.

Возможности данной программы:
- Задачи показываются с номерами и статусами
- Добавлять задачи
- Отмечать задачу выполненной по номеру
- Проверять введенный номер
- Выходить из программы

## Как запустить

Нужен установленный Python 3.14. Открой терминал в папке программы и выполни:

```powershell
python task_manager.py
```

## Пример использования
Первый запуск: файла tasks.json еще нет, поэтому список задач пуст.
Выбор команды 2 и ввод новой задачи «Разобрать меню».
После повторного запуска выбираем команду 1 и видим сохранённую задачу.


```text

python task_manager.py
1 - Показать задачи
2 - Новая задача
3 - Отметить выполненной
0 - Выход
Выбери действие: 2
Новая задача: Разобрать меню
1 - Показать задачи
2 - Новая задача
3 - Отметить выполненной
0 - Выход
Выбери действие: 0
До встречи!

python task_manager.py
1 - Показать задачи
2 - Новая задача
3 - Отметить выполненной
0 - Выход
Выбери действие: 1
1 Разобрать меню
Нужно выполнить
1 - Показать задачи
2 - Новая задача
3 - Отметить выполненной
0 - Выход
Выбери действие: 0
До встречи!

```

Задачи хранятся в файле tasks.json.
Запись выполняется после успешного добавления задачи "2 - Новая задача" и после успешной отметки выполненной — команда 3 тоже сохраняет изменения.
При повторном запуске программа загружает ранее сохранённые задачи из файла.
