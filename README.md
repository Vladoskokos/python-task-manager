# Меню задач.


Данный проект поможет составить список задач.

Возможности данной программы:
- Задачи показываются с номерами и статусами
- Добавлять задачи
- Отмечать задачу выполненной по номеру
- Проверять введенный номер
- Выходить из программы

## Как запустить

Нужен установленный Python 3.14. Открой терминал в папке программы и выполни:

```powershell
python task_manager.py
```
